05 / TROUBLESHOOTING

Common checks

Use the response message before retrying an action.

“Unauthorized” or token error

Confirm the ADMIN_TOKEN value in your hosting environment and enter it exactly. The dashboard sends it in an Authorization Bearer header. Never paste the token into a public message.

No pairing code appears

Check that the service is awake, the number has 8–15 digits including the country code, and the account is eligible to link. Read sanitized server logs if the API returns a generic server error.

Pairing another number

This backend's pair route intentionally replaces the existing local session. Confirm the account-switch checkbox before requesting a new code. You may need to link the new account again.

Health is OK but WhatsApp is disconnected

The health endpoint confirms only that the HTTP service responds. It does not prove WhatsApp is connected or that messages are being handled.

Gemini does not reply

Check that the saved key is valid, the model ID is supported, the backend can reach the provider, and any provider usage limits have not been reached.

Is the token stored by this page?

No. This page keeps the token in the current page field and does not write it to local storage. Clear the field when you finish, especially on a shared device.
